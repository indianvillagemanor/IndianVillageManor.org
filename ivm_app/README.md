# Indian Village Manor Condominiums Website

## This project is the website for Indian Village Manor condominiums in Detroit, Michigan

## Goals

- **Public facing website** describing the condominiums, with photos, amenities, and contact information
- **Private area** for residents to access information about the condominiums, including documents, newsletters and a calendar of events
- **Authentication system** for residents to log in and access the private area
- **An authentication role and interface** for verifying, updating and deleting resident accounts
- **A content management role and interface** for managing the private area content

## Technologies

- **Next.js (App Router)** – React framework for server-side rendering and routing
- **TypeScript** – Type-safe JavaScript for all application code
- **Prisma** – ORM for PostgreSQL database access and migrations
- **PostgreSQL** – Relational database for user and content data
- **NextAuth.js** – Authentication system with email magic links and role support
- **Nodemailer** – Email sending for magic links and verification
- **Tailwind CSS** – Utility-first CSS framework for styling
- **React Hook Form & Zod** – Form management and validation
- **Docker** – Containerization for deployment
- **ESLint & Prettier** – Code linting and formatting
