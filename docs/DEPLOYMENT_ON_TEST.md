# Deployment on Fresh Test Host (Redirect)

This guide has been merged into the canonical parameterized deployment guide.

Use [DEPLOYMENT.md](./DEPLOYMENT.md) and set:

- `HOSTNAME` to your test hostname (example: `sb.stevenlevis.com`)
- `ADMIN_EMAIL` to your ACME contact address
- `APP_DIR` and `COMPOSE_FILE` for your server layout

The canonical guide covers first deployment, redeployment, cert/nginx setup,
verification, and troubleshooting.
